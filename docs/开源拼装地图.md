- 组网：官方 Tailscale 不动（Headscale 早否决）。
- 崩溃上报（Sentry 自托管）：可选，未验证，按需再议。

## 七、CTO 裁决（2026-09-06，用 / 借 / 弃）

> 裁决标准：Windows+WSL2 单 EXE 架构契合度 · 维护负担归属 · 协议 · 是否增加用户侧复杂度 · P0 时间影响。
> 承重核实：Velopack 官方文档存在 Deploy to GitHub Releases（更新源零服务器成本成立）；CasaOS 仅支持 Ubuntu/Debian/RPiOS/CentOS（整体采用否决成立）。

| 项 | 裁决 | 精确理由 |
|---|---|---|
| Velopack | USE | D-01 关闭：安装器+EXE 自更新一体，Rust 原生接入约 10 行，MIT，更新源=GitHub Release。T-10 实施留 2 个验证子项（单实例互斥、vpk runner），不阻塞裁决 |
| winget | USE（主）+ 自有 manifest 兜底 | Win 自带、silent 安装、manifest 带 SHA；旧/LTSC/精简系统无 winget 时才走自有下载。T-08 规格改为此二层 |
| Obtainium | USE（渠道，零代码） | 我们只发 GitHub Release + 引导页加一行；更新推送白嫖。T-12 规格改为此 |
| Syncthing-Fork | USE | 安卓唯一活口；pin 版+二维码+引导，手机侧与 Obtainium 联动双更新 |
| rclone | 条件 USE / bisync DROP(P0) | mount 只做 alist 覆盖不到的远端；bisync 与 Syncthing 同目录混用=损坏风险，P0 禁止 |
| restic | P2 USE 候选 | staggered 是版本、robocopy 是镜像，加密去重备份是真缺口，但无用户需求前不动手 |
| Watchtower | 条件 USE（试点） | 只给非关键容器打 enable 标签；immich/portainer 等 DB 耦合全部排除；更新通知进面板 |
| syncthingtray | 只借鉴不集成 | 托盘已自研，再拼一个托盘=用户困惑；读它的状态呈现与错误映射 |
| CasaOS / Runtipi | 借模型+模板更新通道机制，不整体采用 | 已核实 Linux 绑死；整体采用=双 dashboard，1 EXE 哲学死亡；借 Runtipi 式 git 模板仓机制给未来商店 |
| Cosmos | 冻结 | 协议 Other 看清前不碰 |
| copyparty | DROP(P0) | alist 已够用；第二文件入口=两套认证两套客服；仅当临时分享链接成为付费需求时重议 |
| Nextcloud 提级 | DROP | 随应用商店搁置；PHP 全家桶上 Windows 节点=运维噩梦 |

*CTO 签发 2026-09-06。*
