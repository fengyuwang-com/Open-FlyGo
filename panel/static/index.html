说明
开机自启动来自两类：① 计划任务（带 Logon/Boot 触发，跑起来的是服务/后台）② 注册表 Run 值（HKLM 系统级 / HKCU 当前用户）。
点「停用」即关掉自启：计划任务走 Disable-ScheduledTask，注册表 Run 走删值（原命令已备份，可随时「启用」恢复）。已废弃候选——停用更安全；确认需要时再开启。
停用系统级(HKLM) Run 需要管理员权限：操作失败时，请以管理员身份运行面板后重试。

🔋 保活设置 防止 Syncthing-Fork 被系统杀后台（按厂商）
通用（所有安卓机）
① 设置 → 电池/应用管理 → 找到 Syncthing-Fork → 省电策略/电池优化 = 不限制
② 允许自启动、允许后台活动、锁定任务时保持连接
③ 连接充电器/家庭 WiFi 时保持同步，关屏不断网
小米 / Redmi（HyperOS/MIUI）
设置 → 应用设置 → 应用管理 → Syncthing-Fork → 省电策略：无限制；自启动：允许；后台弹出界面：允许。
另：设置 → 省电与电池 → 右上角齿轮 → 锁屏后断开数据：从不。
华为 / 荣耀（EMUI/MagicOS）
设置 → 应用 → 应用启动管理 → Syncthing-Fork → 手动管理：自启动/关联启动/后台活动全开。
另：设置 → 电池 → 更多电池设置 → 休眠时始终保持网络连接：开。
OPPO / 一加（ColorOS）
设置 → 电池 → 应用耗电管理 → Syncthing-Fork → 允许完全后台行为。
另：设置 → 应用管理 → Syncthing-Fork → 允许自启动。
vivo / iQOO（OriginOS）
设置 → 电池 → 后台耗电管理 → Syncthing-Fork → 允许后台高耗电。
另：设置 → 应用与权限 → 自启动：允许。
三星（One UI）
设置 → 电池 → 后台使用限制 → Syncthing-Fork → 不受限制。
另：应用设置 → 电池 → 允许后台活动。
保活只是「尽力而为」：手机不是服务器，Syncthing-Fork 在前台或充电时同步最快；日常随手打开一次即可完成增量上传。
说明
· 手机只做汇聚源（上传），不是节点；手机上所有同步目录请一律设为「仅发送」。
· 首次同步大相册耗时较长，保持 Syncthing-Fork 前台运行、屏幕常亮可加速。
· 本页每 5 秒自动刷新配对状态；手机浏览器直接打开面板地址也能操作。
