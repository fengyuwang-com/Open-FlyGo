把手机相册与下载目录汇聚到节点：只上传、不回删，全程约 10 分钟
1安装 Tailscale约 1 分钟
Tailscale 在手机与节点之间建立加密通道：在外面用移动网络也能连回家里节点。
手机与节点长期在同一 WiFi 时可以先跳过（第 3 步靠局域网发现也能配对），但建议安装——之后同步不再挑网络。

首次打开会初始化约 10-30 秒，看到「Web GUI」或主界面即就绪；期间保持联网。

4目录设为「仅发送 Send Only」约 1 分钟
仅发送 = 手机只上传。节点侧的任何改动（包括删除）永远不会回传到手机——节点永不反向删手机上的文件。
手机上：Syncthing-Fork → 底部「文件夹」→ ＋ → 选择相册 / 下载等目录；
「文件夹类型」务必选 仅发送（Send Only）；
「共享给设备」勾选第 3 步配对的节点 → 保存；
节点侧：电脑上的 Syncthing 弹「新文件夹」提示，选择保存位置并点「添加」。
注意删除的传播方向：手机上自己删除文件，删除仍会同步、节点副本会跟着删——这是同步工具的正常行为，手机上请谨慎删除。误删后能否找回，取决于节点文件夹是否开启了版本控制。
5保活设置（按厂商）约 2 分钟
安卓厂商默认会杀后台应用。按手机品牌完成下面三件事：电池不限制 + 允许自启动 + 允许后台活动。
小米 / Redmi（HyperOS / MIUI）
设置 → 应用设置 → 应用管理 → Syncthing-Fork → 省电策略：无限制；自启动：允许；后台弹出界面：允许。
另：设置 → 省电与电池 → 右上角齿轮 → 「锁屏后断开数据」：从不。
华为（EMUI / HarmonyOS）
设置 → 应用 → 应用启动管理 → Syncthing-Fork → 关闭「自动管理」，手动管理里 自启动 / 关联启动 / 后台活动 全部允许。
另：设置 → 电池 → 更多电池设置 → 「休眠时始终保持网络连接」：开。
OPPO / 一加（ColorOS）
设置 → 电池 → 应用耗电管理 → Syncthing-Fork → 允许完全后台行为。
另：设置 → 应用管理 → 应用程序 → Syncthing-Fork → 允许自启动：开；耗电管理：允许后台运行。
荣耀（MagicOS）
设置 → 应用 → 应用启动管理 → Syncthing-Fork → 手动管理：允许自启动 / 关联启动 / 后台活动。
另：设置 → 电池 → 更多电池设置 → 「休眠时始终保持网络连接」：开。
保活是尽力而为，不是保证：手机不是服务器。App 在前台运行或充电时同步最快；日常随手打开一次 Syncthing-Fork，即可完成增量上传。
