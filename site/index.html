产品形态

对外交付只有两个文件，内部复杂度全部封装。

1 个 EXE + 1 个 APK

电脑端一个可执行文件，手机端一个安装包。Docker、内网穿透、命令行的复杂度都在软件内部消化，拿到即用。

按需启动，不常驻空转

常驻内存十几到几十 MB。点开媒体中心才拉起容器，存储在被访问时才挂载；用完即停，不占后台。

数据不经平台

同步在设备之间 P2P 直连完成，文件不经过飞狗服务器。控制面只处理元数据，平台无权限读取或删除文件。

设备无关

闲置手机、旧电脑、移动硬盘都能当节点。节点损坏后换任意设备，扫码激活，数据从其他节点自动恢复。

常见问题

AGPL 是什么？

FlyGo 按 AGPL v3 协议开源：任何人都可以免费使用、修改和分发软件；基于修改版本提供网络服务时，同样需要开放修改后的源码。对普通使用没有影响——本地功能免费、无期限，也不需要激活码。

订阅激活了什么？

激活的是服务，不是软件：控制面组网（身份、激活码、心跳）、跨设备互备编排、硬件换新保障（非人为故障跨品牌换新）。面板、文件服务、局域网同步、镜像备份等本地功能不订阅也完整可用；订阅到期只停服务，不停本地功能与已有数据。

需要什么设备？

节点用闲置设备即可：安卓手机（建议 Android 12 及以上、存储 1TB 起）或任意 Windows / macOS / Linux 电脑。使用端：手机安装 APK，电脑运行单文件可执行程序。版本对应节点数量：单机版 1 台、双保险版 2 台、三节点版 3 台。

我的数据在哪？

数据只存在自己的设备里：原始数据在各设备本地一份，汇聚到节点一份，多节点再互备一份。同步走设备间 P2P 直连（Tailscale + Syncthing），文件内容不经过飞狗服务器；飞狗无权限读取或删除文件。

断网能用吗？

局域网内的同步与文件访问不依赖外网。断网期间，已同步的数据在本地照常可用；网络恢复后，设备之间自动比对差异并补齐，外网访问（Tailscale）也同时恢复。
